# Guidebook screenshots

Drop PNG files here using the **exact filenames** below. Chapters reference `./assets/<name>.png`.

**Important:** Put images on their own line — **not** inside a markdown blockquote (`>`).

**Cursor tip:** The in-tab Preview toggle may not show images. Use **Markdown: Open Preview to the Side** (Command Palette) instead. GitHub renders them fine after push.

## How to add

1. Capture the UI at a readable desktop width (≈1280px+).
2. Prefer PNG; avoid heavy compression on text UI.
3. Save with the filename listed (no spaces).
4. In the chapter, use: `![Caption](./assets/filename.png)`
5. Optional: crop chrome that is not part of the caption.
